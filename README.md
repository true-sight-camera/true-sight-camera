# true-sight-camera
Camera Code for TrueSight Camera

This is still a work in progress for our engineering capstone, so code is disorganized, however below is our poster for more infomration on how our product works!

![TrueSight Poster](https://github.com/user-attachments/assets/9836c004-e776-4c94-9370-9f10a7656d59)

The code here is a bunch of test scripts and camera GUI code that will capture an image, assign a signature and depth data, and upload the signed image to a cloud service for use to send on any social media platform.

Most relevant code for how our camera system works is under gui, everything else is mainly testing code. cron.sh is used as the entrypoint to run the code on our Raspberry Pi.

This readme and code will be cleaned up at a later date, but stay tuned!
